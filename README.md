# Python IDE for Android

Красивый прототип Android IDE для Python на Jetpack Compose.

## Что уже есть
- файловая панель проекта;
- редактор Python-кода с базовой подсветкой синтаксиса;
- встроенный терминал с поддержкой команд `ls`, `python <file>` и `pip install <package>`;
- быстрый блок для установки пакетов через `pip`;
- тёмная адаптивная UI-композиция под планшеты и смартфоны.

## Стек
- Kotlin
- Jetpack Compose
- Material 3

## Как открыть
1. Откройте проект в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на Android-устройстве или эмуляторе.

## Что можно улучшить дальше
- подключить реальную файловую систему через Storage Access Framework;
- встроить настоящий Python runtime для запуска скриптов;
- добавить полноценный терминал с историей и автодополнением;
- расширить подсветку синтаксиса и форматирование кода.
